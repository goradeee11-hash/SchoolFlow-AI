# SchoolFlow AI — MVP 0.1

نسخة تجريبية أولى لمعلم واحد (منتصر)، تعمل محليًا على الكمبيوتر.

## الأدوات
- Python: لغة تشغيل التطبيق.
- Streamlit: واجهة ويب بسيطة لرفع Excel وعرض النتائج.
- pandas و openpyxl: قراءة Excel والحسابات وتصدير التقارير.
- IBM Bob أو VS Code: فتح الملفات وتعديل الكود بمساعدة الذكاء الاصطناعي.

## التشغيل على Windows

1. ثبّت Python 3.11 أو أحدث من [python.org](https://python.org)، مع تفعيل **Add Python to PATH**.
2. فك ضغط مجلد المشروع.
3. افتح PowerShell داخل مجلد `SchoolFlow_AI_MVP`.
4. نفّذ الأوامر التالية:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

5. سيفتح التطبيق في المتصفح تلقائيًا.

> **ملاحظة:** إذا لم يعمل الأمر `py`، استخدم المسار الكامل لـ Python:
> `& "C:\Users\<اسمك>\AppData\Local\Programs\Python\Python314\python.exe" -m pip install -r requirements.txt`

## ملف البيانات التجريبية

يحتوي المشروع على ملف `sample_data.xlsx` — **بيانات وهمية فقط** — لاختبار التطبيق دون الحاجة لبيانات حقيقية.

### بنية الملف المتوقعة

| التفصيل | القيمة |
|---|---|
| اسم الورقة | `Weekly tracking` |
| صف العناوين | الصف الخامس (header=4 في pandas) |
| الصفوف 1–4 | عنوان / معلومات وصفية (لا تُقرأ كبيانات) |

### الأعمدة المطلوبة (إنجليزية)

| العمود | الوصف |
|---|---|
| `Student code` | رمز الطالب (مثل S01) |
| `Week` | رقم الأسبوع |
| `Days scheduled` | أيام التدريس المجدولة |
| `Days attended` | أيام الحضور الفعلي |
| `Tasks set` | عدد المهام المعيّنة |
| `Tasks completed` | عدد المهام المنجزة |
| `Quiz score / 10` | درجة الاختبار من 10 |
| `Observation` | ملاحظة المعلم |
| `Next step` | الخطوة التعليمية القادمة |

### عمود اختياري

| العمود | الوصف |
|---|---|
| `Student name` | اسم الطالب — إذا وُجد، يُستخدم في رسائل أولياء الأمور بدلاً من الرمز |

## ميزات النسخة الحالية

### 1. رفع Excel وقراءة الأعمدة
- يقرأ ورقة `Weekly tracking` تلقائيًا (أو يتيح اختيار الورقة).
- يُنشئ تدفق بيانات جديدًا في كل قراءة لتجنب أخطاء مؤشر الملف عند التحديث.

### 2. مراجعة جودة البيانات
يعرض التطبيق جدول المشكلات **قبل** التحليل. يكشف عن:
- قيم مفقودة في أي عمود رقمي.
- درجة اختبار غير مسجلة (يُميّز بين **صفر حقيقي** وقيمة **مفقودة**).
- حضور أكبر من الأيام المجدولة.
- مهام منجزة أكبر من المهام المعيّنة.
- الصفوف المشكلة **لا تُحذف تلقائيًا** — منتصر يرى المشكلة ويقرر.

### 3. اسم الطالب الاختياري
- إذا وُجد عمود `Student name`، يُستخدم في رسائل أولياء الأمور ورؤوس القوائم.
- إذا غاب العمود، يُستخدم رمز الطالب (بدون إيقاف التطبيق).

### 4. ملخصات الأداء
- **ملخص أسبوعي للفصل**: الحضور ونسبة إنجاز المهام ومتوسط الاختبارات لكل أسبوع.
- **ملخص كل طالب**: نسب الحضور والمهام ومتوسط الاختبارات عبر جميع الأسابيع.

### 5. تفاصيل أسبوعية لطالب محدد
- اختر أي طالب من القائمة لعرض سجله أسبوعًا بأسبوع.

### 6. رسائل أولياء الأمور
- تُنتج رسالة لكل طالب باللغة العربية **أو** الإنجليزية.
- تعرض الرسالة في حقل نصي قابل للمراجعة والتعديل قبل الإرسال.
- لا يوجد إرسال تلقائي — المعلم يراجع كل رسالة.

### 7. تنزيل تقرير Excel
- يُصدر ملف `SchoolFlow_AI_Report.xlsx` يحتوي على ثلاث أوراق:
  - `Validated data` — البيانات النظيفة.
  - `Student summaries` — ملخص كل طالب.
  - `Weekly summary` — الملخص الأسبوعي.
